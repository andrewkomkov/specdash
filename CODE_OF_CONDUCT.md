# Code of Conduct

## The short version

Be decent. Assume the other person is trying to help. Argue about the work, not about the
person doing it.

## The specifics

Expected: courtesy, directness, and taking disagreement as information rather than as an
attack. Saying "this is wrong because X" is welcome; the value of a review is in the X.

Unacceptable: harassment of any kind, personal or demographic attacks, deliberate
intimidation, publishing private information, or sustained disruption of a discussion.

## Scope and enforcement

This applies in the repository, its issues and its pull requests.

Report a problem to the maintainer through a private GitHub message or the security advisory
form. Reports will be handled discreetly. The maintainer may edit or remove contributions
that break these rules, and may block accounts that keep breaking them.

This is adapted from the spirit of the [Contributor Covenant](https://www.contributor-covenant.org)
without adopting its full text, because a document nobody reads protects nobody.
